# 文件分块下载

![license](https://img.shields.io/badge/license-MPL--2.0-green)
![python](https://img.shields.io/badge/python-3.8%2B-blue)

本工具将大文件按指定大小切分为多个分片，并生成记录文件信息与校验值的清单文件。使用者可依据清单文件在本地或远程获取全部分片，合并还原为原始文件。

适用于受单文件大小限制的大文件传输场景，例如邮件附件、论坛上传、静态托管、对象存储等；也可用于向未下载本工具的用户分发大文件（网页版）。

## 功能概览

| 功能 | 说明 |
|------|------|
| 文件分块 | 按指定大小切分源文件，输出分片与清单文件，并记录完整性校验值 |
| 文件合并 | 读取本地清单文件与同目录分片，合并还原原始文件 |
| 远程下载 | 通过清单文件地址获取分片清单，下载后合并还原 |
| 并发下载 | 多个分片同时下载，并发数量可配置 |
| 断点续传 | 中断后保留已下载分片，再次开始时跳过完整分片 |
| 校验方式 | 双校验、只校验分片、只校验整文件、不校验四档可选 |
| 失败重试 | 单个分片失败不影响其余分片，整轮结束后自动重试未完成的分片 |
| 增强模式 | 模拟浏览器请求特征，用于访问存在反爬限制的站点 |
| 多端支持 | 聚合界面、独立界面、网页版，共用同一分片格式 |

## 快速开始

### 可执行程序

前往 [Releases](https://github.com/zsh-cn/fkxz/releases) 下载对应程序，解压后运行，无需安装 Python 环境。

| 程序 | 文件名 | 说明 |
|------|--------|------|
| 聚合程序 | `wjfkxz.exe` | 集成文件分块与文件下载，侧边栏切换 |
| 文件分块 | `wjfk.exe` | 仅提供分块功能 |
| 文件下载 | `wjxz.exe` | 仅提供合并与远程下载功能 |

设置项与窗口位置等偏好保存在程序所在目录的 `settings.json`。

### 源码运行

```bash
git clone https://github.com/zsh-cn/fkxz.git
cd fkxz
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt

python main.py                  # 聚合程序
python wjfk.py                  # 文件分块
python wjxz.py                  # 文件下载
```

Linux 环境如缺少 `tkinter`，需先安装：`sudo apt install python3-tk`。

### 网页版

访问项目官网的[在线体验页面](https://fkxz.zhshh.cn/wjxz/experience)，或自行部署 `web/` 目录（见[网页端部署](#网页端部署)）。

## 使用说明

### 文件分块

1. 选择要分块的源文件，也可直接输入路径，或把文件拖入窗口
2. 选择输出目录，留空时保存到程序所在目录；目录不存在时自动创建；程序会记住上次填写的目录
3. 确认输出文件名，默认取源文件名，可修改
4. 设置分片大小，范围 1–1024 MB，默认 10 MB
5. 选择校验方式，决定清单中写入哪些校验信息
6. 点击「开始分块」，过程中可取消

界面会显示源文件大小与预计分片数，分块过程中显示进度、已处理数据量与传输速度。进度同时映射到 Windows 任务栏。开始前会检查输出目录的可用空间。

完成后输出目录内容：

```
{文件名}-1.fk
{文件名}-2.fk
...
{文件名}.fkx
```

将分片与清单文件上传至同一目录，即可通过清单文件的访问地址分享。同名分片在重复分块时会被覆盖。

**校验方式**

| 选项 | 清单内容 | 适用场景 |
|------|----------|----------|
| 双校验（分片 + 整文件） | 每片校验值 + 整文件校验值 | 默认，完整性要求最高 |
| 只校验分片 | 仅每片校验值 | 快速分块，仍可逐片校验 |
| 只校验整文件 | 仅整文件校验值 | 分片数量很多时减少计算开销 |
| 不校验（仅核对大小） | 不写入校验值 | 追求速度，可接受仅核对字节数 |

分块要求源文件可读、输出目录可写；分块过程中源文件被修改或截断时，已生成的分片会被清理并报错。

**完成后打开文件夹**

勾选窗口左下角的「完成后打开文件夹」后，分块成功结束会自动打开输出目录。未勾选时可通过「打开文件夹」按钮手动打开。

**完成后关机**

勾选窗口左下角的「分块完成后关机」后，分块成功结束即开始 60 秒关机倒计时。倒计时窗口可点击「取消关机」继续使用计算机，此时关闭程序同样会撤销关机。取消或失败的任务不会触发关机。


### 文件下载与合并

输入框支持远程地址与本地路径，程序根据输入类型切换模式。

输入或选择有效的清单文件后，程序自动获取并解析清单，显示文件名、文件大小与分片数量。清单文件也可以直接拖入窗口。

输出目录可以留空，此时保存到程序所在目录；填写目录后会被记住。

**本地模式**

选择本地清单文件与输出目录，点击「开始合并」。程序读取同目录下的分片，确认齐备后合并还原。

**远程模式**

填写清单文件地址，选择输出目录，按需设置增强模式与校验方式，调整并发数量后点击「开始下载」。程序依次完成清单获取、清单校验、分片下载、合并还原与校验，成功后按设置清理或保留临时分片目录。失败后已下载的分片不会重复下载；单个分片失败时其余分片继续下载，整轮结束后自动重试未完成的分片。

下载与合并的进度同步显示在 Windows 任务栏上。

**增强模式**

默认启用，需安装 `curl_cffi`。启用后模拟 Chrome 浏览器的请求特征，兼容 Cloudflare 验证、防盗链等访问限制；未安装该依赖时选项不可用，程序自动使用标准请求方式。

**校验方式**

下拉框四档可选，含义与分块端一致：

| 选项 | 行为 |
|------|------|
| 双校验（分片 + 整文件） | 下载时逐片校验，合并后再校验完整文件 |
| 只校验分片 | 仅逐片校验，跳过整文件比对 |
| 只校验整文件 | 跳过逐片校验，合并后比对整文件 |
| 不校验（仅核对大小） | 只核对文件总字节数 |

清单缺少对应校验值时会自动降级。

解析清单后，下拉框只保留该清单支持的校验方式。校验失败时删除结果文件并提示。

**断点续传**

已下载的分片保存在输出目录下的临时目录中，合并成功后默认自动删除。再次开始时，完整分片直接复用，未完成分片从已有长度继续；服务器不支持断点请求时，该分片重新下载。临时目录被删除后需从头下载。

分片校验结果会缓存到临时目录中，依据文件大小与修改时间判断是否可复用。

**完成后打开文件夹**

勾选窗口左下角的「完成后打开文件夹」后，下载或合并成功结束会自动打开输出目录。未勾选时可通过「打开文件夹」按钮手动打开。

**完成后关机**

勾选窗口左下角的「下载/合并完成后关机」后，任务成功结束即开始 60 秒关机倒计时。倒计时窗口可点击「取消关机」继续使用计算机，此时关闭程序同样会撤销关机。取消、失败或中断的任务不会触发关机。

**下载完成后自动删除分片**

窗口左下角的「下载完成后自动删除分片」默认勾选，下载成功结束后自动删除输出目录下的临时分片目录，仅保留合并还原的文件。取消勾选后分片目录会被保留，状态栏会显示其位置，便于再次合并或重复使用；该开关会被记住。本地模式合并的是原始分片目录，无论是否勾选都不会删除分片。


### 聚合程序

左侧边栏提供「文件分块」「文件下载」两个入口，点击切换，无需打开多个窗口。两个功能在切换后保留原有状态，关闭主窗口时统一结束进行中的任务。两个功能各自在界面左下角提供完成关机开关，两个开关互不影响。

### 网页端部署

`web/` 目录为静态页面，无需后端服务：

```
web/
├── index.html     # 下载页面
├── sw.js          # 清单解析、分片获取与合并脚本
└── favicon.png    # 站点图标
```

部署步骤：

1. 将上述文件放置于同一静态目录（页面与 Service Worker 均需 `sw.js`，不可缺省）
2. 站点需使用 HTTPS 或 localhost 访问，且脚本与页面同源
3. 通过地址参数传入清单文件位置：

```
https://your-domain.com/index.html?fkx=https://example.com/files/video.mp4.fkx
```

4. 页面自动加载清单并显示文件信息，点击「下载」后由浏览器完成文件保存

网页端说明：

- 分片所在服务器需允许跨域访问，否则浏览器会拦截请求
- 服务器支持断点请求时续传效率更高，不支持时功能仍可用，但会重复传输部分数据
- 网页端不进行完整性校验，仅按清单长度合并分片
- `fkx` 参数仅接受 http(s) 地址或相对路径
- 页面功能依赖 Service Worker，注册失败时无法下载

## 文件格式

### 清单文件（`.fkx`）

命名格式为 `{原文件名}.fkx`，内容为纯文本键值对：

```
filename=video.mp4
chunk_size=10485760
num_chunks=3
chunk_1=video.mp4-1.fk,10485760,<分片1校验值>
chunk_2=video.mp4-2.fk,10485760,<分片2校验值>
chunk_3=video.mp4-3.fk,5242880,<分片3校验值>
total_size=26214400
sha256=<完整文件校验值>
```

| 字段 | 说明 |
|------|------|
| `filename` | 还原后的文件名（必填） |
| `chunk_size` | 分片大小（字节） |
| `num_chunks` | 分片数量，须与条目数一致 |
| `chunk_N` | 分片文件名、大小、校验值，编号自 1 起且连续；校验值可省略 |
| `total_size` | 文件总大小（字节），须与各分片大小之和一致 |
| `sha256` | 完整文件校验值，选择不写入整文件校验时该行缺省 |

清单在解析阶段即校验字段一致性：编号不连续、编号重复、数量或总大小不符会直接报错。


### 分片文件（`.fk`）

命名格式为 `{原文件名}-{编号}.fk`，编号自 1 起。分片为源文件的连续字节切分，除最后一片外大小一致。

## 环境要求

| 项目 | 要求 |
|------|------|
| Python | 3.8 及以上 |
| 必需依赖 | `requests`、`tkinter`（标准库） |
| 可选依赖 | `curl_cffi`，用于增强模式；未安装时自动使用标准请求方式 |
| 操作系统 | Windows、Linux、macOS（拖放文件、任务栏进度仅 Windows） |

```bash
pip install -r requirements.txt
```

网页版要求：支持 Service Worker 的现代浏览器，站点使用 HTTPS 或 localhost，分片服务器允许跨域访问。

## 打包

```bash
pip install pyinstaller
pip install -r requirements.txt
```

```bash
# 文件分块
pyinstaller --onefile --windowed --name wjfk --distpath dist \
  --icon icon/wjfk.ico --add-data "icon;icon" wjfk.py

# 聚合程序
pyinstaller --onefile --windowed --name wjfkxz --distpath dist \
  --icon icon/wjfkxz.ico --add-data "icon;icon" main.py

# 文件下载
pyinstaller --onefile --windowed --name wjxz --distpath dist \
  --icon icon/wjxz.ico --add-data "icon;icon" --hidden-import curl_cffi wjxz.py
```

产物输出至 `dist/`。图标目录需随程序一同打包，否则运行时无法加载窗口与任务栏图标；文件下载程序需显式包含 `curl_cffi`，否则增强模式在打包后不可用。`build/` 目录与 `.spec` 文件可删除。
