# 文件分块下载 - 大文件分片传输工具

## 项目官网

项目官网提供了项目介绍、下载页面、在线体验和文档页面，欢迎访问：

- **主站**：[https://fkxz.zhshh.cn](https://fkxz.zhshh.cn)
- **备用站**：[https://zsh-cn.github.io/fkxz/](https://zsh-cn.github.io/fkxz/)

## 官网结构

```
docs/                              # 项目官网
│   ├── index.html                 # 官网主页
│   ├── download.html              # 下载页面
│   ├── dev.html                   # 文档页面
│   ├── favicon.png                # 官网图标
│   ├── dist/                      # 打包可执行程序输出目录
│   │   ├── wjfk.exe
│   │   ├── wjfkxz.exe
│   │   └── wjxz.exe
│   ├── css/                       # 样式文件
│   │   └── style.css
│   ├── js/                        # 公共脚本
│   │   └── main.js
│   ├── icons/                     # 程序图标
│   │   ├── wjfk.ico
│   │   ├── wjfkxz.ico
│   │   └── wjxz.ico
│   └── wjxz/                      # Web 在线下载体验页面
│       ├── index.html
│       ├── sw.js
│       ├── experience.html
│       └── favicon.png
└── LICENSE                        # MPL 2.0 许可证
```
