使用说明

各程序的详细使用方法

wjfkxz.exe — 聚合程序

集成文件分块与文件下载两大功能，侧边栏一键切换

启动

双击 wjfkxz.exe 即可启动。

使用方式

  • 左侧边栏提供「文件分块」「文件下载」两个入口，点击切换，无需打开多个窗口
  • 两个功能在切换后保留原有状态
  • 关闭主窗口时统一结束进行中的任务
  • 两个功能各自在界面左下角提供完成关机开关，两个开关互不影响

各功能的具体操作请参考下方 wjfk.exe 与 wjxz.exe 的使用说明。

独立 GUI 程序

wjfk.exe — 文件分块

将大文件分块为多个小分片，并生成记录校验值的清单文件

使用步骤

  1. 选择要分块的源文件，也可直接输入路径，或把文件拖入窗口
  2. 选择输出目录，留空时保存到程序所在目录；目录不存在时自动创建，程序会记住上次填写的目录
  3. 确认输出文件名，默认取源文件名，可修改
  4. 设置分片大小，范围 1–1024 MB，默认 10 MB
  5. 选择校验方式，决定清单中写入哪些校验信息
  6. 点击「开始分块」，过程中可取消

界面会显示源文件大小与预计分片数，分块过程中显示进度、已处理数据量与传输速度，进度同时映射到 Windows 任务栏。开始前会检查输出目录的可用空间。

分块完成后会在输出目录生成：

  • {文件名}-1.fk、{文件名}-2.fk、... — 分片文件
  • {文件名}.fkx — 清单文件

将分片与清单文件上传至同一目录，即可通过清单文件的访问地址分享。同名分片在重复分块时会被覆盖。

校验方式

选项 清单内容 适用场景
双校验（分片 + 整文件） 每片校验值 + 整文件校验值 默认，完整性要求最高
只校验分片 仅每片校验值 快速分块，仍可逐片校验
只校验整文件 仅整文件校验值 分片数量很多时减少计算开销
不校验（仅核对大小） 不写入校验值 追求速度，可接受仅核对字节数

分块要求源文件可读、输出目录可写；分块过程中源文件被修改或截断时，已生成的分片会被清理并报错。

完成后打开文件夹

勾选窗口左下角的「完成后打开文件夹」后，分块成功结束会自动打开输出目录。未勾选时可通过「打开文件夹」按钮手动打开。

完成后关机

勾选窗口左下角的「分块完成后关机」后，分块成功结束即开始 60 秒关机倒计时。倒计时窗口可点击「取消关机」继续使用计算机，此时关闭程序同样会撤销关机。取消或失败的任务不会触发关机。

wjxz.exe — 文件下载与合并

读取清单文件，下载分片并合并还原，支持本地与远程两种模式

输入与识别

  • 输入框支持远程地址与本地路径，程序根据输入类型切换模式
  • 输入或选择有效的清单文件后，程序自动获取并解析清单，显示文件名、文件大小与分片数量
  • 清单文件也可以直接拖入窗口
  • 输出目录可以留空，此时保存到程序所在目录；填写目录后会被记住

本地模式

  1. 选择本地清单文件与输出目录
  2. 点击「开始合并」

程序读取同目录下的分片，确认齐备后合并还原。

远程模式

  1. 填写清单文件地址（如 https://example.com/files/video.mp4.fkx）
  2. 选择输出目录，按需设置增强模式与校验方式
  3. 调整并发数量后点击「开始下载」

程序依次完成清单获取、清单校验、分片下载、合并还原与校验，成功后清理临时文件。失败后已下载的分片不会重复下载；单个分片失败时其余分片继续下载，整轮结束后自动重试未完成的分片。下载与合并的进度同步显示在 Windows 任务栏上。

增强模式

  • 默认启用：需安装 curl_cffi，启用后模拟 Chrome 浏览器的请求特征，兼容 Cloudflare 验证、防盗链等访问限制
  • 不可用时：未安装该依赖时选项不可用，程序自动使用标准请求方式

校验方式

下拉框四档可选，含义与分块端一致：

选项 行为
双校验（分片 + 整文件） 下载时逐片校验，合并后再校验完整文件
只校验分片 仅逐片校验，跳过整文件比对
只校验整文件 跳过逐片校验，合并后比对整文件
不校验（仅核对大小） 只核对文件总字节数

清单缺少对应校验值时会自动降级；解析清单后，下拉框只保留该清单支持的校验方式。校验失败时删除结果文件并提示。

断点续传

已下载的分片保存在输出目录下的临时目录中，合并成功后自动删除。再次开始时，完整分片直接复用，未完成分片从已有长度继续；服务器不支持断点请求时，该分片重新下载。临时目录被删除后需从头下载。分片校验结果会缓存到临时目录中，依据文件大小与修改时间判断是否可复用。

完成后打开文件夹 / 完成后关机

勾选窗口左下角的「完成后打开文件夹」后，下载或合并成功结束会自动打开输出目录。勾选「下载/合并完成后关机」后，任务成功结束即开始 60 秒关机倒计时，倒计时窗口可点击「取消关机」继续使用计算机，此时关闭程序同样会撤销关机。取消、失败或中断的任务不会触发关机。
