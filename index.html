文件分块下载

把大文件切成小分片，上传更省事；下载时并发拉取、断点续传、失败自动重试，并按四档校验策略还原成原文件。

下载已打包程序 在线体验
Windows 10 / 11 Python 3.8+ MPL-2.0

主站 · 备用站

核心能力

从分块、分发到并发下载与完整性校验，一条链路解决大文件传输

文件分块

按 1–1024 MB 自定义分片大小（默认 10 MB），切成多个 .fk 分片并生成 .fkx 清单。

文件下载与合并

本地 .fkx 直接合并，或按清单地址远程下载分片后合并还原。

四档校验

双校验、只校验分片、只校验整文件、不校验四档可选，清单缺少对应校验值时自动降级。

断点续传

已下载分片保留在临时目录，再次开始时跳过完整分片，未完成分片用 Range 从断点继续。

并发与重试

并发数量可调；单个分片失败不影响其余分片，整轮结束后自动重试未完成的分片。

增强模式

集成 curl_cffi 模拟 Chrome 请求特征，兼容 Cloudflare、防盗链等访问限制。

完成即关机

可勾选完成后自动打开输出目录；也可勾选任务结束后关机，倒计时期间随时取消。

少一步操作

文件可直接拖入窗口，输出目录留空即用程序所在目录，并记住上次填写的目录。

多端支持

聚合界面、独立界面与网页版共用同一分片格式，程序可运行于 Windows / Linux / macOS。

三步上手

分块、上传、分享链接，对方即可下载还原

1

分块文件

拖入文件、设置分片大小与校验方式后开始分块，得到多个 .fk 和一个 .fkx。

2

上传到服务器

把分片与清单一起上传到同一目录，无需改变服务器配置，也无需支持断点请求。

3

分享与下载

分发 .fkx 的链接，对方用桌面程序或网页端下载、校验并还原成原文件。

快速开始

源码运行或直接下载 exe，两种方式任选其一

git clone https://github.com/zsh-cn/fkxz.git
cd fkxz
python -m venv .venv        # 创建虚拟环境（可选）
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # Linux / macOS
pip install -r requirements.txt
python wjfk.py                 # 启动分块 GUI
python wjxz.py                 # 启动下载 GUI
python main.py                 # 启动聚合 GUI

无需安装 Python 环境，下载已打包程序后直接运行。支持 Windows 系统，开箱即用。

前往下载页 最新 Release

wjfkxz.exe 为聚合程序，wjfk.exe 与 wjxz.exe 为独立程序，按需选择其一即可。

多端支持

提供多种使用方式，满足不同场景需求

聚合 GUI 程序

一个聚合入口，集成文件分块与文件下载两大功能，侧边栏一键切换。

  • wjfkxz.exe：单个窗口完成分块与下载
  • 切换功能后保留各自状态，关闭窗口统一结束任务
  • 四档校验方式，失败分片自动重试
  • 断点续传与并发数量可调

独立 GUI 程序

两个独立工具，各司其职，可按需只取其中一个。

  • wjfk.exe：仅文件分块
  • wjxz.exe：本地合并与远程下载
  • 完成后可自动打开文件夹或关机
  • 增强模式：curl_cffi 浏览器模拟

网页端工具

轻量级浏览器端工具，无需安装任何软件。

  • Service Worker 流式合并下载
  • 纯前端实现，无需后端支持
  • 可用浏览器下载管理器暂停与继续
  • 不做完整性校验，仅按清单长度合并
