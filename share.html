四步拿到文件

不用关心分片在哪、有几块，工具会按清单自动处理。

下载并解压

把上面的 zip 解压到任意目录，双击 wjfkxz.exe 或 wjxz.exe。

粘贴清单链接

把收到的 .fkx 链接粘贴进程序地址框，或直接把清单文件拖进窗口。

选择保存位置

确认显示的文件名与大小无误，指定输出目录，其余保持默认即可。

开始下载

程序并发拉取分片、自动重试、按清单校验，最后拼回原文件。

常见问题

为什么不能直接在浏览器里下载？

可以，但不是首选。分片通常存放在不同域名下，浏览器要求服务器显式允许跨域才能读取；长连接下载中断后也往往只能从头再来，而且浏览器端不做 SHA-256 校验。

桌面工具走的是普通 HTTP 请求，不受跨域限制，支持分片级断点续传与完整性校验，几十 GB 的文件也能稳定跑完。

提示「无法读取清单」怎么办？

这通常是清单所在服务器未开启跨域（CORS），只影响本页面的预览展示，不影响下载。把上方的 .fkx 链接复制到工具里，仍然可以正常下载。

需要注册、登录或付费吗？

不需要。工具完全本地运行，没有账号体系，也不依赖任何后端服务。

分片文件要自己一个个下载吗？

不用。清单里记录了每个分片的文件名、长度与校验值，工具会据此自动拼出地址并并发拉取。你只需要那一个 .fkx 链接。

文件太大，下载中途断了会重来吗？

不会。已下载完整的分片会被保留并复用，未完成的分片用 HTTP Range 从断点继续，直接重新点「开始下载」即可。

能在 macOS / Linux 上用吗？

源码可以在 Python 3.8+ 环境运行（界面基于 Tk）。官方预编译程序面向 Windows 10 / 11。
