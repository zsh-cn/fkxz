选择下载方式

桌面程序更稳（断点续传 + 完整性校验），Windows 10 / 11 解压即用；也可以不下载，用网页版直接下载。

推荐

聚合程序 wjfkxz.exe

分块与下载合并二合一，平时分块、收文件都用它。

  • 「文件分块」与「文件下载」双界面
  • 并发、断点续传、四档校验齐全
  • 可直接拖入 .fkx 或粘贴链接
下载 wjfkxz.zip GitHub 备用源

独立程序 wjxz.exe

只负责下载与合并，体积更小，适合只是来收文件的你。

  • 只保留下载、合并、校验
  • 启动更快，界面更简单
  • 与聚合版共用同一分片格式
下载 wjxz.zip GitHub 备用源

在线下载 无需安装

用浏览器打开网页版，逐片拉取并在本地合并保存；在 Chrome 中可暂停后续传。

要求清单与分片所在服务器允许跨域；网页端不做 SHA-256 校验，仅按长度合并。

在线下载 打开在线体验 →

下载教程

两种方式，按手头条件选一种即可。

网页版

无需安装
  1. 在「选择下载方式」里点「在线下载」。
  2. 新页面自动读取清单，显示文件名与大小。
  3. 点「下载」，浏览器逐片拉取并在本地合并保存。

要求清单与分片服务器允许跨域；Chrome 中可暂停后续传；网页端不做 SHA-256 校验。

下载程序

Windows 10 / 11
  1. 下载 zip 并解压到任意目录。
  2. 双击 wjfkxz.exe（或 wjxz.exe）。
  3. 粘贴 .fkx 链接。
  4. 选好保存位置，点「开始下载」，程序自动拉取、校验并还原。

支持分片级断点续传与四档校验。
