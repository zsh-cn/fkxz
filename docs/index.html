文件分块下载

将大文件拆分为多个小分片，支持本地合并与远程下载合并，可用于绕过文件上传大小限制或便于文件传输

下载已打包程序 GitHub 仓库

项目功能特点

一站式大文件分片传输解决方案

文件拆分

将大文件按指定大小拆分为多个 .fk 分片，并生成 .fkx 信息文件

本地合并

读取 .fkx 信息文件和同目录下的 .fk 分片，自动合并还原为原始文件

远程下载

从远程服务器下载分片，自动合并还原，支持 SHA-256 完整性校验

增强模式

集成 curl_cffi 浏览器指纹模拟，伪装 Chrome 请求头，绕过反爬虫保护

多端支持

CLI 命令行、新版 GUI、旧版独立 GUI、网页端工具，多种使用方式

跨平台

Python 工具支持 Windows / Linux / macOS；网页端支持所有现代浏览器

实时进度

终端进度条 / GUI 进度条，实时显示分块进度、总进度和下载速度

自动清理

远程下载完成后自动清理临时分片文件

多端支持

提供多种使用方式，满足不同场景需求

命令行工具 (CLI)

基于 argparse 的统一命令行入口，提供 split / merge / download 三大命令，适合批处理和脚本自动化场景。

  • SHA-256 完整性校验
  • 增强模式：curl_cffi 浏览器指纹模拟
  • 自定义超时时间（默认 120 秒）
  • 终端实时进度条显示
  • 下载完成后自动清理临时文件

新版 GUI 应用

Tkinter 现代化图形界面，采用侧边栏导航设计，集成三大功能于一体。

  • 侧边栏导航，三页无缝切换
  • 自定义圆角进度条和按钮组件
  • HiDPI 高 DPI 自适应
  • 多线程异步处理，界面不阻塞
  • 实时分块进度 + 总进度 + 下载速度
  • 文件信息预览（文件名、大小、分片数）
  • 支持取消操作
  • 右键上下文菜单

旧版独立 GUI

两个独立的 Tkinter 图形界面工具，分别专注于拆分和下载/合并。

  • file_splitter.py：文件拆分器
  • file_downloader.py：文件下载/合并器
  • 支持本地模式和远程模式
  • SHA-256 完整性校验
  • 增强模式：curl_cffi 浏览器指纹模拟

网页端工具

轻量级浏览器端工具，无需安装任何软件。

  • index.html：浏览器端文件下载器
  • sw.js + sw.html：Service Worker 下载器
  • worker.js：Cloudflare Workers 后端
  • 纯前端实现，无需后端支持
  • 支持流式下载和实时进度

快速开始

三种方式，任选其一

# 克隆仓库
git clone https://github.com/zsh-cn/fkxz.git
cd fkxz

# 基础安装
pip install .

# 安装后直接使用 fkxz 命令
fkxz split -i ./video.mp4 -o ./chunks -c 10
fkxz merge -i ./chunks/video.mp4.fkx -o ./output
fkxz download -u https://example.com/files/video.mp4.fkx -o ./output

# 如需增强模式（浏览器指纹模拟）
pip install ".[enhanced]"
fkxz download -u https://example.com/files/video.mp4.fkx -o ./output --enhanced
# 克隆仓库
git clone https://github.com/zsh-cn/fkxz.git
cd fkxz

# 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # Linux / macOS

# 安装依赖
pip install -r requirements.txt

# 启动新版 GUI
python app/main.py

# 或使用 CLI
python cli/main.py split -i ./video.mp4 -o ./chunks -c 10

# 或使用旧版 GUI
python file_splitter.py
python file_downloader.py

前往 下载页面 获取最新版本的已打包 .exe 程序，解压后直接双击运行即可，无需安装 Python 环境。

文件格式说明

了解 .fkx 和 .fk 文件的格式定义

.fkx 信息文件

命名格式：{原文件名}.fkx（如 video.mp4.fkx）

filename=原始文件名
total_size=文件总字节数
chunk_size=分片字节数
num_chunks=分片总数
chunk_0=分片文件名,分片大小
chunk_1=分片文件名,分片大小
...
sha256=原始文件SHA-256值

.fk 分片文件

命名格式：{原文件名}-{索引}.fk

网页端工具

无需安装，浏览器直接使用

Cloudflare Workers

部署 worker.js 到 Cloudflare Workers，流式合并分片并提供直链下载。

  • 自动解析 .fkx 文件获取分片列表
  • FixedLengthStream 流式合并
  • 自动设置 Content-Disposition 触发浏览器下载
  • 支持跨域（CORS）
# 访问格式
https://your-worker.workers.dev/?fkx=https://example.com/file.fkx

网页端下载器

纯前端实现的浏览器端文件下载器，支持流式下载和实时进度显示。

  • 纯前端实现，无需后端支持
  • 支持流式下载和实时进度显示
  • 自动检测并使用 File System Access API
  • 支持回退到传统下载方式
# 访问格式
https://your-domain.com/index.html?fkx=https://example.com/file.fkx

Service Worker 下载器

基于 Service Worker 的浏览器端下载器，SW 拦截请求并流式合并分片。

  • 无需 File System Access API，兼容性更好
  • 合并过程不阻塞主线程
  • 直接触发浏览器原生下载
  • 通过 SW 代理绕过 CORS 限制
# 访问格式
https://your-domain.com/sw.html?fkx=https://example.com/file.fkx

PyInstaller 打包说明

如果你想自行从源码打包为 .exe 可执行程序

# 安装 PyInstaller
pip install pyinstaller
pyinstaller --onefile --console --name cli --icon icon/wjfkxz-cli.ico cli/main.py
  • --onefile：打包为单个 exe 文件
  • --console：控制台程序（显示命令行窗口）
  • --name cli：输出文件名为 cli.exe
  • --icon icon/wjfkxz-cli.ico：设置 exe 程序图标
pyinstaller --onefile --windowed --name main --icon icon/wjfkxz.ico --add-data "icon;icon" --add-data "app;app" app/main.py
  • --windowed：窗口程序（不显示命令行窗口）
  • --icon icon/wjfkxz.ico：设置 exe 程序图标
  • --add-data "app;app"：将 app 模块打包进去
  • 任务栏/窗口图标：icon/wjfkxz.png
pyinstaller --onefile --windowed --name file_splitter --icon icon/wjfk.ico --add-data "icon;icon" file_splitter.py
  • --icon icon/wjfk.ico：设置 exe 程序图标
  • 任务栏/窗口图标：icon/wjfk.png
pyinstaller --onefile --windowed --name file_downloader --icon icon/wjxz.ico --add-data "icon;icon" --hidden-import curl_cffi file_downloader.py
  • --icon icon/wjxz.ico：设置 exe 程序图标
  • --hidden-import curl_cffi：显式包含 curl_cffi 模块
  • 任务栏/窗口图标：icon/wjxz.png

打包说明

  • 打包后的 exe 文件位于 dist/ 目录下
  • 如果增强模式打包失败或运行时不可用，程序会自动回退到标准 requests 模式
  • 建议在打包前先执行 pip install -r requirements.txt 和 pip install ".[enhanced]" 确保所有依赖已安装
  • 对于 main.exe，请确保 app/ 目录及其子模块（core/、ui/、utils/）均被正确包含
