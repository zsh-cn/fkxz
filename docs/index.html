文件分块下载

主站 | 备用站

将大文件拆分为多个小分片，支持本地合并与远程下载合并，可用于绕过文件上传大小限制或便于文件传输

下载已打包程序 GitHub 仓库

项目功能特点

一站式大文件分片传输解决方案

文件拆分

将大文件按指定大小拆分为多个 .fk 分片，并生成 .fkx 信息文件

文件下载

支持本地 .fkx 合并还原与远程 URL 下载分片合并，自动识别输入类型，支持 SHA-256 完整性校验

增强模式

集成 curl_cffi 浏览器指纹模拟，可伪装 Chrome 浏览器请求头（User-Agent、Sec-Ch-Ua、Sec-Fetch-* 等），绕过 Cloudflare 验证、EdgeOne Pages、防盗链等反爬虫保护

多端支持

提供命令行工具（CLI）、聚合 GUI 程序（集成侧边栏）、独立 GUI 程序、网页端工具等多种使用方式

跨平台

Python 工具支持 Windows / Linux / macOS；网页端支持所有现代浏览器

实时进度

终端进度条 / GUI 进度条，实时显示分块进度、总进度和下载速度

自动清理

远程下载完成后自动清理临时分片文件

多端支持

提供多种使用方式，满足不同场景需求

命令行工具 (CLI)

基于 argparse 的统一命令行入口，提供 split / merge / download 三大命令，适合批处理和脚本自动化场景。

  • SHA-256 完整性校验
  • 增强模式：curl_cffi 浏览器指纹模拟
  • 自定义超时时间（默认 120 秒）
  • 终端实时进度条显示
  • 下载完成后自动清理临时文件

聚合 GUI 程序

Tkinter 现代化图形界面，采用侧边栏导航设计，集成文件分块与文件下载两大功能于一体。

  • 侧边栏导航，两页无缝切换
  • 文件下载页面自动识别本地/远程模式
  • 实时分块进度 + 总进度 + 下载速度
  • 文件信息预览（文件名、大小、分片数）
  • 支持取消操作
  • 右键上下文菜单

独立 GUI 程序

两个独立的 Tkinter 图形界面工具，分别专注于拆分和下载/合并。

  • file_splitter.py：文件拆分器
  • file_downloader.py：文件下载/合并器
  • 支持本地模式和远程模式
  • SHA-256 完整性校验
  • 增强模式：curl_cffi 浏览器指纹模拟

网页端工具

轻量级浏览器端工具，无需安装任何软件。

  • index.html：浏览器端文件下载器
  • sw.js + sw.html：Service Worker 下载器
  • worker.js：Cloudflare Workers 后端
  • 纯前端实现，无需后端支持
  • 支持流式下载和实时进度

快速开始

pip 安装、源码运行或直接下载，三种方式任选其一

# 克隆仓库
git clone https://github.com/zsh-cn/fkxz.git
cd fkxz

# 基础安装
pip install .

# 安装后直接使用 fkxz 命令
fkxz split -i ./video.mp4 -o ./chunks -c 10
fkxz merge -i ./chunks/video.mp4.fkx -o ./output
fkxz merge -i ./chunks/video.mp4.fkx -o ./output -s
fkxz download -u https://example.com/files/video.mp4.fkx -o ./output

# 如需增强模式（浏览器指纹模拟）
pip install ".[enhanced]"
fkxz download -u https://example.com/files/video.mp4.fkx -o ./output --enhanced
# 克隆仓库
git clone https://github.com/zsh-cn/fkxz.git
cd fkxz

# 创建虚拟环境（可选）
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # Linux / macOS

# 安装依赖
pip install -r requirements.txt

# 启动聚合 GUI
python app/main.py

# 或使用 CLI
python cli/main.py split -i ./video.mp4 -o ./chunks -c 10

# 或使用独立 GUI
python file_splitter.py
python file_downloader.py
